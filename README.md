# spds
STHOLOLWAZI PROJECTS DRAWING STANDARD (SPDS)
Version: 1.0
Status: Company Standard
Owner: Sthololwazi Projects
Scope: Residential, Commercial, Industrial, Infrastructure, Renovation, Additions & Alterations

Vision

To establish a single, coordinated digital documentation standard that enables Sthololwazi Projects to consistently produce professional architectural and construction documentation for any project while ensuring technical quality, regulatory compliance, operational efficiency, and a recognizable company identity.

This standard becomes more than a template—it becomes the firm's operating system for documentation.

Core Principles

Every project should:

Look unmistakably like a Sthololwazi Projects drawing package.
Use identical drafting conventions and sheet organization.
Follow standardized notes and specifications.
Generate schedules automatically where possible.
Maintain complete cross-sheet coordination.
Be easy to revise without introducing inconsistencies.
Scale from a small residence to a commercial development.

Volume 1 — Company Standards Manual

This becomes the authoritative reference for every project and defines:

Drawing numbering
Sheet naming
Fonts
Lineweights
Colours (for on-screen coordination; printed drawings remain monochrome unless otherwise required)
Dimension styles
Annotation standards
Revision practices
Title block format
Company branding
Logo placement
Scale conventions
Issue status (Concept, Tender, IFC, As-Built)

This is your equivalent of a BIM or CAD standards manual.

End Goal

The long-term objective is not simply to own a set of drawing templates. It is to establish the Sthololwazi Projects Drawing Standard (SPDS) as the company's authoritative documentation platform.

Every future project—whether a new house, a commercial building, a warehouse, a retaining wall, or a renovation—would begin from this standard. That ensures every drawing package carries the same professional presentation, technical consistency, and coordinated structure, reinforcing the Sthololwazi Projects brand while reducing production time and improving quality across all deliverables.
